# Sprint audit

This repository starts with an audited application snapshot. The existing hosted project retains its source history and reviewed homework separately. The public clone includes a synthetic homework sample and excludes worksheet transcriptions, original answer keys, prior screenshots, and production settings.

| Area | Observed state |
| --- | --- |
| Arcade | A vanilla JavaScript shell presents three mode cards to either fantasy identity. The runner uses Three.js. Both original platform adventures run in isolated frames and use shared physics. |
| Worlds and study | Seven runner environments with three gameplay stages each, independent study levels, two original question banks, JSON schemas, and replay rewards. Original Adventure uses its own existing courses. |
| Reading Detective | Guided mission state, paragraph checks, evidence matching and paper confirmation exist. The sprint regression covers optional keywords, touch scrolling, multi-span evidence and the seven-question private case. |
| Accounts | Same-origin Worker with D1, SQLite development adapter, explorer PINs, remembered sessions and rotated QR recovery. Physical Photos, Files and camera behavior remains a device check. |
| Economy | Profile-separated wallets, reward ledger, 60 species, food, visible equipment, XP and Common-only free starters. Browser purchase fixtures initially assumed the former unrestricted starter rule. |
| Admin | Existing server-authorized homework publishing is independent of the new Game Master tools. Production enablement requires a strong owner secret. |
| Test infrastructure | Node tests, Playwright Chromium/WebKit and a shared clean-install GitHub Actions workflow. Real-device performance, memory, background resume and audio remain manual checks. |
